# Infrastructure-Revamp
A guide to using "swig" to replace parts of existing pythonic code with C++ without complete alteration of codebase.  
We will need [Xournal++](https://xournalpp.github.io/) to view .xopp files  
Checkout branches and tags in the codebase for better understanding of the checkpoints
